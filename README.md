# 📱 Keuanganku — Aplikasi Manajemen Keuangan Pribadi

**Keuanganku** adalah aplikasi mobile untuk mencatat dan mengelola keuangan pribadi.  
Aplikasi ini dibuat menggunakan **Flutter** dan **Firebase** dengan berbagai fitur seperti pencatatan transaksi, grafik pengeluaran, sistem anggaran, laporan PDF, hingga login biometrik.

Aplikasi ini bertujuan membantu pengguna memantau pemasukan dan pengeluaran secara sederhana namun informatif.

---

# 🚀 Fitur Utama

### 🔐 Autentikasi
- Login menggunakan Email & Password
- Login menggunakan **Fingerprint / Biometric**
- Logout akun

### 💰 Manajemen Transaksi
- Tambah transaksi
- Edit transaksi
- Hapus transaksi (Swipe delete)
- Riwayat transaksi real-time dari Firebase

### 📊 Dashboard Keuangan
- Total saldo
- Total pemasukan
- Total pengeluaran
- Grafik pengeluaran (Pie Chart)
- Filter transaksi berdasarkan bulan

### 🗂 Kategori Transaksi
Contoh kategori:
- Makanan
- Transport
- Belanja
- Investasi
- Gaji

### 📈 Sistem Anggaran (Budget)
- Menentukan budget per kategori
- Progress bar penggunaan budget
- Peringatan jika budget hampir habis

### 🤖 AI Spending Insight
Aplikasi memberikan insight otomatis seperti:
- Kategori pengeluaran terbesar
- Persentase pengeluaran
- Saran penghematan

### 📄 Export Laporan PDF
- Generate laporan transaksi
- Ringkasan keuangan
- Share atau simpan PDF

### 🌙 Dark Mode
- Toggle Light Mode / Dark Mode
